# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform created by Amazon. It provides many different services that organizations can use for computing, storage, databases, networking, security, and other IT needs. AWS started in 2006 and has grown into one of the major cloud platforms used by businesses around the world.

## Global Infrastructure

AWS has a large global infrastructure made up of Regions and Availability Zones. AWS currently lists 39 launched Regions and 123 Availability Zones. Availability Zones are separated locations inside a Region that help applications remain available even when problems affect one location.

## Cloud Management Console

The AWS Management Console is a web-based interface where users can create, configure, monitor, and manage AWS resources. Instead of using only command-line tools, users can use the console to work with services such as EC2, S3, databases, networking, and security.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and websites.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store files, images, videos, backups, and other types of data. S3 was one of the first major AWS services when AWS launched in 2006.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create an isolated virtual network for their AWS resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls who can access AWS resources and what actions they are allowed to perform.

## Three Advantages

1. AWS provides a very large selection of cloud services.
2. AWS can scale resources according to the needs of a business.
3. Its global infrastructure allows organizations to deploy applications in different parts of the world.

## Typical Enterprise Use Cases

AWS can be used by enterprises for websites, mobile applications, data storage, backup systems, databases, business applications, artificial intelligence, and large-scale e-commerce platforms.
