# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It allows organizations to build, deploy, and manage applications and services using Microsoft's global cloud infrastructure. Azure was launched in 2010 and has grown into a large cloud platform with many products and services.

## Global Infrastructure

Azure has a worldwide infrastructure organized into geographies and regions. Azure geographies contain one or more regions and are designed to support requirements such as data residency, availability, and compliance.

## Cloud Management Console

The Azure Portal is the web-based management interface for Microsoft Azure. Users can use it to create, configure, monitor, and manage Azure resources from a browser.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual servers that can run Windows or Linux operating systems.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, and backups.

### 3. Azure Virtual Network

Azure Virtual Network allows cloud resources to communicate securely with each other and with other networks.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management. It helps organizations control users, applications, and access to cloud resources.

## Three Advantages

1. Azure works especially well with Microsoft's existing technologies.
2. It provides many tools for enterprise organizations.
3. It supports hybrid cloud environments and integration with existing IT infrastructure.

## Typical Enterprise Use Cases

Azure can be used for Windows Server workloads, Microsoft 365-related environments, databases, enterprise applications, virtual machines, data analytics, artificial intelligence, and hybrid cloud systems.

## My Understanding

I think Azure is a strong option for organizations that already depend heavily on Microsoft products. It can make the transition to cloud computing easier because many familiar Microsoft technologies can work together with Azure.
