# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory activity focused on exploring and comparing three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

I learned that each cloud provider offers similar basic services, but they have different strengths and are designed for different types of users and organizations.

## What I Investigated

During this laboratory, I researched:

* Amazon Web Services (AWS)
* Microsoft Azure
* Google Cloud Platform (GCP)
* Cloud computing services
* Cloud infrastructure
* Virtual machines
* Object storage
* Identity management
* Kubernetes
* Cloud platform recommendations

## Cloud Services That Could Host the Linux Server

The Linux server could be hosted using virtual machine services from all three cloud providers.

| Cloud Provider  | Possible Service       |
| --------------- | ---------------------- |
| AWS             | Amazon EC2             |
| Microsoft Azure | Azure Virtual Machines |
| Google Cloud    | Compute Engine         |

These services provide virtual machines where a Linux operating system can run.



## Mission Summary

This activity helped me understand that cloud providers are similar in many basic services, but their strengths can be different. AWS has a very broad range of services, Azure is a strong choice for Microsoft environments, and Google Cloud is especially strong for AI, data, and Kubernetes.

The most important lesson I learned is that choosing a cloud provider should depend on the actual needs of the organization instead of simply choosing the most popular provider.
