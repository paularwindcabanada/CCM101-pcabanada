# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment and the basic responsibilities of a cloud engineer.

## Objectives

- Access a cloud-based Linux environment.
- Explore the Linux operating system.
- Gather system information.
- Organize files and directories.
- Create a GitHub portfolio.
- Document technical work using Markdown.

## Activities Performed

I accessed the KillerCoda Linux Playground, created a Linux user, explored the Linux environment, gathered system information, created a workspace, and prepared my GitHub Cloud Computing Portfolio.
